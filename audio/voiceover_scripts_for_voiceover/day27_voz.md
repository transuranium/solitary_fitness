Día 27. Lista completa de ejercicios, del uno al dieciséis.

Ejercicio uno: zancadas. Una serie de diez repeticiones por cada pierna.
Ejercicio dos: elevación de pierna recta hacia adelante, o sobre apoyo. Una serie de diez repeticiones por cada pierna.
Ejercicio tres: saltos estrella. Una serie de diez repeticiones.
Ejercicio cuatro: sentadillas. Una serie de diez repeticiones.

Ejercicio cinco: zancadas. Una serie de doce repeticiones por cada pierna.
Ejercicio seis: elevación de pierna recta hacia adelante, o sobre apoyo. Una serie de doce repeticiones por cada pierna.
Ejercicio siete: saltos estrella. Una serie de doce repeticiones.
Ejercicio ocho: sentadillas. Una serie de doce repeticiones.

Ejercicio nueve: zancadas. Una serie de quince repeticiones por cada pierna.
Ejercicio diez: subir la rodilla y estirar la pierna hacia adelante, con control, como una patada. Una serie de quince repeticiones por cada pierna.
Ejercicio once: saltos estrella. Una serie de quince repeticiones.
Ejercicio doce: sentadillas profundas. Una serie de quince repeticiones.

Ejercicio trece: zancadas. Una serie hasta el fallo por cada pierna.
Ejercicio catorce: subir la rodilla y estirar la pierna hacia adelante, con control. Una serie hasta el fallo por cada pierna.
Ejercicio quince: saltos estrella. Una serie hasta el fallo.
Ejercicio dieciséis: sentadillas. Una serie hasta el fallo.
Si haces la versión alternativa, en el ejercicio dieciséis haces una serie de hasta cincuenta repeticiones.


День 27. Полный список упражнений, с первого по шестнадцатое.

Упражнение первое: выпады. Один подход по десять повторений на каждую ногу.
Упражнение второе: подъём прямой ноги вперёд, или на опору. Один подход по десять повторений на каждую ногу.
Упражнение третье: прыжки «звёздочка». Один подход по десять повторений.
Упражнение четвёртое: приседания. Один подход по десять повторений.

Упражнение пятое: выпады. Один подход по двенадцать повторений на каждую ногу.
Упражнение шестое: подъём прямой ноги вперёд, или на опору. Один подход по двенадцать повторений на каждую ногу.
Упражнение седьмое: прыжки «звёздочка». Один подход по двенадцать повторений.
Упражнение восьмое: приседания. Один подход по двенадцать повторений.

Упражнение девятое: выпады. Один подход по пятнадцать повторений на каждую ногу.
Упражнение десятое: поднять колено и выпрямить ногу вперёд, с контролем, как удар ногой. Один подход по пятнадцать повторений на каждую ногу.
Упражнение одиннадцатое: прыжки «звёздочка». Один подход по пятнадцать повторений.
Упражнение двенадцатое: глубокие приседания. Один подход по пятнадцать повторений.

Упражнение тринадцатое: выпады. Один подход до отказа на каждую ногу.
Упражнение четырнадцатое: поднять колено и выпрямить ногу вперёд, с контролем. Один подход до отказа на каждую ногу.
Упражнение пятнадцатое: прыжки «звёздочка». Один подход до отказа.
Упражнение шестнадцатое: приседания. Один подход до отказа.
Если ты делаешь альтернативную версию, то в упражнении шестнадцатом выполняешь один подход до пятидесяти повторений.
